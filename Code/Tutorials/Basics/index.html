PROGRAMMING!

There's nothing better than programming, right?

Programming is the art (?) of telling the computer what to do in order to create beautiful and well designed games or applications

But how does programming work?
Well, computers do not speak a language like me and you (unless your talking about LLM AIs, fuck AI)
Computers are machines made of souless silicon that execute logic and (kinda of) mathematical operations
So in order to create something like a game you need to translate the rules of the game into math and logic. Sounds boring and hard? Because it is for 99% of sane people, but somehow insane people like me find it fun.

How does that work?

Great question!

See, computers are just pieces of circuit in a square of 99.9902% pure silicion

But circuits don't change, so you would need a different circuit for every program, and that does not scale

So the nerds had a great idea: the CPU would have a bunch of prebuilt operations in the circuits, and programs would be built using them, activating the right circuits at the right order. And that is called an instruction-set or architecture (they are different things but aren't at the same time and i'm too lazy do explain)

But people quickly realized that writing raw instructions by their binary code (the zeros and ones) is extremely tedious, prone to human error and horrible for later changes in code. People tried to make machine code more legible by creating something called Assembly (which is often considered the first programming language)
